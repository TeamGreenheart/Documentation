5Customizing Theme

All three sites use the same Greenheart theme. Site-wide elements such as the menus, footer and homepage are managed outside the block editor, mostly in the Customizer (Appearance › Customize).

Greenheart Admin role required

Menus and Customizer settings can only be changed by a Greenheart Admin. If you're a Greenheart Editor, request changes through the Web Issue Form.

Using the Customizer

  1. Go to Appearance › Customize. A preview of the site opens, with the settings in a panel on the left.
  2. Open a panel (for example Theme Footer), then a section, and make your changes. The preview updates as you go.
  3. Nothing is live until you click Publish. To leave without saving, close the Customizer with the × at the top left.

Colors

The Greenheart palette is built into the editor. Pick colors from the palette instead of entering custom values, so the site stays on brand.

Typography

Headings use Sanchez and body text uses Lato. Use heading levels in order (H2, then H3) so the page has a clear structure and is accessible.

Menus

Each site has two menus, managed under Appearance › Menus:

  • Primary Menu: the main navigation in the header
  • Footer Menu: the links in the footer
  1. Choose the menu to edit from the Select a menu to edit dropdown, then click Select.
  2. Add pages, content items or custom links from the panels on the left.
  3. Drag items to reorder them. Drag an item slightly to the right to make it a sub-item.
  4. Click Save Menu.
Tip

When you rename or move a page, its menu link updates automatically. Custom links don't, so check them after you change a page's address.

Homepage

The top of each homepage is set in the Customizer, not in the page editor.

Homepage Slider

The rotating slides at the top of the homepage. Add and order slides under Slides; set the title, subtitle and aspect ratio under Homepage Slider Settings.
